# 桌面仪表基础组件

2026-10-12，用户打回真实截图中与系统主题割裂的组件，要求完整、适配本软件的基础组件样式。本次优先级高于新增办公工具；便签/待办已写的业务代码保留，视觉验收随组件接入一起进行。

## 设计约束

保留本软件深蓝灰、玉绿、暖白和少量香槟色方向，不再让默认纯黑输入框、方形复选框和各页自绘按钮混用。材质用于表达层级，不能遮盖文字；图片用于品牌和图标，输入控件、边界和反馈用可缩放 Rust 绘制，不为每个状态增加整张纹理。

| 基础项 | 统一规则 |
| --- | --- |
| 颜色 | BACKGROUND/SURFACE/FIELD/CONTROL 分层；ACCENT 表示选择、焦点及正常；WARNING 表示注意；DANGER 表示错误或确认删除；禁用单列颜色 |
| 字体 | 沿用中文字体安装链路；输入与正文 14px，标签 12–13px，卡片标题 16–18px；不更换为仅有英文字形的字体 |
| 尺寸 | 常规选择项 36px，主操作 48px；小图标操作按场景 26/30/36px，不强行放大宠物区域；输入最小 36px，内边距 12×9px |
| 圆角 | 控件 10px，复选框 7px，状态标签 6px，内容卡片与弹窗 16px；内外层分级 |
| 交互 | 闲置、悬停、按下、选中、键盘焦点、禁用均有区分；焦点描边玉绿，错误描边柔红；完整标签和操作说明保留，不能只靠颜色 |
| 动效 | 控件状态变化克制；开关约 80ms，静止不持续动画；不加 GPU 模糊或后台绘图线程 |

## 代码职责

`src/ui/common/theme.rs` 是颜色和尺寸源。`components/` 按职责分层：`surface` 处理操作状态，`fields` 处理输入，`selection` 处理选择项/复选框/设备下拉，`status` 处理标签和消息，`layout` 处理列表行和弹窗外壳。

既有 `actions`、`icons`、`widgets` 沿用调用入口，但共用以上主题。主次操作与危险操作、导航选中、页签、截图模式、图标悬停、开关、数值控制、列表行、确认弹窗因此能跨页面一致。输入保留 egui 原生编辑、选区、快捷键和 IME 路径，不自己实现文本引擎。全局视觉设置同时约束滑块、数值输入、颜色选择器等原生控件。

业务页面禁止自行选择新颜色来替代正常/注意/错误含义；新页面先复用组件，确需增加组件时同时补预览和交互测试。报告只读正文继续可选择复制；设备选择保持原来的自动选择和已离线设备回显规则。资源监视器的用户自选颜色不被本次固定界面主题覆盖。

## 真实预览与验收

`--office-preview <尚不存在的绝对目录>` 使用真实 Glow 窗口、中文字体、生产组件和合成办公数据，依次输出便签、待办、编辑、提醒、组件画廊、监测项和设备页。只读取自身 GL 缓冲；不抓取用户桌面，不启动资源采样、托盘、清理或用户数据存储。预览结果带 PID、完成阶段数和错误状态。

组件画廊不是生成设计图：它与业务页面调用同一套函数，可操作选择、开关、输入、数值和下拉。图片检查关注控件材质一致、文字对齐、错误边界、禁用可辨认、按钮可达和小窗口滚动。截图结果不能代替全部 DPI、多屏和日常交互验收。

原有检查为什么未拦住：以往回归主要验证按钮出现、数据变更和窗口位置，没有共享视觉契约，页面直接调用默认控件仍会通过。新增实际中文输入/限制/焦点边界、复选框键盘/禁用、状态色和真实页面编辑保存回归；运行期截图补上视觉检查。egui 0.31 的 TextEdit 返回内侧文字矩形，公共包装恢复外侧矩形再画焦点，避免错误边框包住文字。
