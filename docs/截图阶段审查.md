## 领域与应用

- 选区用物理坐标，支持副屏负坐标、反向框选，交集与容量检查在分配之前。
- 自由形状实际透明遮罩，轮廓外 RGBA 全清零，零面积报错。图片上限128 MiB；批注128项，单笔最多1024点，并限制总绘制工作量，避免巨大笔迹让导出长时间阻塞。
- 原图 Arc 共享；批注导出在短命工作线程进行，单任务限制；取消在提交结果前复查，失败保留旧预览。关闭预览时输出已开始则完成该次明确操作后释放图像。
- 窗口来源保存 handle/PID，确认和捕获前后复查可见性、来源和几何。识别和捕获排除/隐藏自己的工具，不声称还原被遮挡内容。

## Windows 与存储

- GDI DC、位图和 SelectObject 状态成对释放；读取 DIB 前 GdiFlush，关闭选区后捕获前 DwmFlush；测试捕获仅使用合成内存 DC。
- 修正初版剪贴板 NULL 所有者问题：创建自己的消息窗口再 OpenClipboard；CF_DIBV5 保留 alpha，系统接收成功后转移全局内存所有权。开发检查没有清空或写入用户剪贴板。
- 修正初版透明色键导致点击穿透的问题：选区仅用整体 alpha，窗口接收完整区域输入，背景变暗属于选区提示。
- PNG 写入同目录临时文件，关闭/同步后 MoveFileW 发布，目标存在则失败，不覆盖；支持不提供硬链接的文件系统。异常只清理自己的临时文件，极端情况下删除失败可能留下 .partial。

## UI 与接线

- 设置和宠物工具分支均连接实际截图页；四种模式必须主动点“开始”，仅浏览页面不会捕获。
- 修正水平布局继承导致四张模式卡片横向溢出，修正新增螺旋动作撑出窗口、九项侧栏挤入底栏；最小窗口和四角镜像回归继续启用，没有放宽边界断言。
- 画布显示原图及当前批注，复制/保存/贴图使用统一 render 结果；预览限制纹理尺寸，导出保持原分辨率。单张贴图可拖动、缩放、关闭，截图时暂时隐藏。
- 保存目录进入既有配置持久化；关闭预览释放原图和纹理，关闭贴图释放贴图和纹理；工具窗口不占任务栏。
- 小贴图使用紧凑缩放/关闭图标，180px窗口回归检查实际图标和文本边界；整个贴图复用原生位置约束，避免拖出屏幕。原生边界检查不套用设置页标题栏命中区，避免吞掉贴图按钮。
