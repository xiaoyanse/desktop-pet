# 本地便签与待办

2026-10-12，承接用户已选便签、待办管理和待办提醒需求。设置新增“便签与待办”，宠物办公分支提供两个实际入口；不接没有功能的可点击占位。

便签可新建、编辑、搜索、收藏到列表顶部、确认删除。待办复用正文编辑，并提供完成/重新打开、到期时间、本地时间显示、无提醒和30分钟/1小时/24小时预设。收藏不是桌面置顶便签，本阶段没有实现独立桌面便签窗。

提醒仅在本应用运行时发生，无声音、不激活窗口。到期后显示靠近宠物的轻提示卡，可完成、10分钟后提醒、本次忽略或打开列表。相同到期事件在本次运行中只入队一次；忽略和延期保存后跨重启生效，未处理事件重启会再次提醒。队列最多64项，处理后补后续条目；系统睡眠期间不执行，恢复后的下一次更新识别错过的时间。未实现循环任务、Windows计划任务或云同步。

数据按“UI → 应用服务 → 接口 → 本地存储”接线，领域数据不依赖窗口/系统API。默认在可执行文件所在盘的 `DesktopMeterData/Office/workspace.json`（本机E盘）保存，只在用户确认保存或条目状态操作后写入；不把未保存的编辑草稿当成已经持久化。

存储用同目录独占新临时文件、写入并同步、备份上一版，然后Windows原子替换。损坏文件、未知版本、超限文件不会被新空文件覆盖；载入失败只读，提供重新载入。保存失败保留原条目和编辑草稿，可以重试；存储前检查外部变化，拒绝已检测到的旧版覆盖。该检查不是对所有外部写入程序的互斥锁，不承诺任意并发编辑安全。备份供人工核查，尚无自动恢复界面。

数据上限：便签/待办合计512项，标题256 UTF-8字节、正文32 KiB、全部文字2 MiB、序列化文件16 MiB。UI进一步限制标题64字符、正文8192字符。日期格式固定为 `YYYY-MM-DD HH:mm`，用Windows当前时区转换并回读验证；夏令时歧义遵循Windows规则。

加载和每次保存使用单个短期工作线程，不建立持续轮询线程。不允许保存并发；成功收到磁盘结果后才更新列表/关闭编辑。已提交保存进行中请求退出会等结果，失败时取消退出并显示提示；退出时服务也等待已接受任务。尚未做断电、强制进程终止和长时间磁盘故障的现场验证。

实际egui输入回归覆盖新建、保存失败保留草稿、重试、编辑、收藏、确认删除、无效日期和提醒操作；本地适配器用E盘自有文件验证备份、损坏/版本/容量拒绝和外部变更。原生预览使用合成数据与真实生产组件，不触碰用户办公文件；证据见《本轮验证》及《基础组件与办公审查》。日常提醒/重启恢复仍待用户实例现场验收。
