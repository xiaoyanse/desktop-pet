# 剪贴板历史

2026-10-12，阶段二十三收尾：已接设置页“剪贴板历史”和宠物办公卡片右上方复制图标，涵盖已选E05文字/图片历史、搜索、固定、删除及容量限制。沿用现有主题，不引入运行时Node/Python/WebView，不扩展到云同步或任意文件执行。真实跨软件复制/粘贴仍待用户实测。

## 明确的行为

每次启动默认关闭，只在用户主动开启后记录新发生的复制；开启时不读取已有内容。暂停立即停止接受新历史，关闭页面不等于暂停。历史只在本次运行的内存中保存，退出清空，不把敏感文本或图片写入磁盘。固定表示避免自动淘汰并置于列表前方，不代表跨重启持久化。支持文字全文搜索、文字/图片筛选、再次复制、单条删除及全量清空确认；清空历史不清空系统当前剪贴板。

默认最多30条、32 MiB，可调数量和容量；单文字限256 KiB，单图片限32 MiB，缩略图也纳入历史容量。优先淘汰最旧未固定项；固定项超预算时拒绝新项目并解释，不默默删除固定内容。重复内容复用原条目/固定状态并更新顺序。超过容量、格式不支持、设备读取被占用及写入失败有明确反馈，不能显示伪成功。全部固定内容无法容纳新的容量时拒绝容量调整。

Windows采用事件监听，只在手动启用时建立一个非可见message-only窗口和工作线程，关闭后移除监听并释放。结果通道有界；快速连续复制可能合并到最新可读取内容，不能保证恢复系统已经覆盖的中间内容。取消后忽略旧结果，停止过程不阻塞界面；停止未完成时不创建第二个监听线程。输入格式以Unicode文字、常见24/32位DIB/DIBV5及PNG为目标；不主动读取文件列表、HTML等未支持内容。

系统剪贴板锁只在拷贝有界原始字节时持有，释放后才解码、建缩略图和计算重复签名。发布通道最多一项；正在读取/解码的工作项及复制任务还会占用少量临时内存，因此历史容量不是整个进程的内存上限。停止即时撤销结果接受，后台退出前保留服务的停止状态；应用退出不会在UI线程等待其他程序的延迟渲染。已完成线程正常回收；仍受外部同步调用阻塞的本进程线程随进程退出，不声称可强制解除外部程序阻塞。

页面列表虚拟化，只给可见行载入缩略图，筛选为空、离开页面或关闭设置时释放页面纹理。关闭页面不停止已开启记录；容量、删除/清空和内容预览使用统一主题居中弹窗，支持取消及Esc/外部关闭。固定项优先显示，减少容量时先校验固定项目；失败保留旧政策和全部固定内容。复制任务最多一个，结果/退出检查不阻塞UI。

数据/容量在domain，监听/复制契约在interfaces，生命周期和失败在application，Win32及图片解码在infrastructure，页面/缩略图/确认在ui/work_tools/clipboard。复制图片复用现有DIBV5发布链路；保存的原图与缩略图分开，复制不能误用低分辨率预览。

## 验证边界

开发中使用合成文本、图片与假的监听/输出，禁止读取或改写用户当前剪贴板。核心回归覆盖默认不启动、开启/暂停/恢复/取消旧结果、预算/固定/重复/失败、DIB方向/像素/alpha和恶意尺寸、有界PNG及原始分辨率复制、真实UI点击及清空取消。原生验证仅操作自有窗口或自身缓冲；实际个人剪贴板抓取/目标程序粘贴及跨软件格式仍需现场验收。不以自动测试代替真实粘贴或用户最终视觉认可。

补充真实Win32元数据监听测试：禁止内容读取分支，仅注册、接收Ready、停止及回收线程，覆盖正常与启动即取消；即使测试期间用户自行复制也不会调用GetClipboardData。另有合成生产UI原生页：未开启空态、文字/图片历史、容量弹窗和清空确认。
