# 桌面仪表阶段测试版

版本：0.1.0-preview.25.20261012。Windows x64，免安装；这是阶段测试版，不是全部需求交付或最终验收版。

本补丁纠正宠物仅导航到管理页面的体验：宠物“工具”直接提供全屏、矩形区域、自由形状和识别窗口截图，点击后立即进入对应模式；成功后才打开批注，Esc取消回到宠物，原先打开的管理窗口恢复原页。宠物“办公”直接开始/暂停/继续/结束会议，工作计时与清理确认维持既有直接操作。齿轮图标用于配置/详情，不必先打开管理页才能启动截图或会议。日常原生输入、真实选区/桌面截图仍请现场确认。

## 启动与恢复

1. 将整个测试包保留或解压到 E 盘。不要直接在 ZIP 内运行。
2. 更换版本时，先右键现有托盘图标，选择退出，然后双击 `启动设置.cmd`。应用采用单实例机制：旧版未退出时，新版启动请求会转到旧版，不能据此检查新版。
3. 新版会打开设置。关闭设置后继续常驻；退出应用请用托盘菜单。
4. 配置继续使用 `%LOCALAPPDATA%\DesktopMeter\settings.json`。本包没有自动更改开机启动路径；开启了开机启动时，请在确认新版可用后检查对应设置，避免下次登录启动旧版。
5. 如需回到旧版，先退出测试版，再启动原程序。本包不会删除原程序或个人数据。旧版不能保证读取新版新增功能数据，不要把此操作理解为全部数据格式可逆。

## 尚未包含和验收边界

- 工作区启动器、手动录音和回溯时间胶囊尚未实现。按用户最新要求，本轮在剪贴板阶段收尾，不再继续扩展；三个需求保持登记。
- 录屏、OCR、屏幕取色仍属候选，没有纳入本次测试。
- 已接入代码不代表现场全部通过：真实截图/粘贴、多屏与不同缩放、重复悬停及连续动画、日常提醒和终版视觉仍需实测。
- 内存按尽量优化处理，不承诺所有状态低于 100 MB。本阶段没有新增内存长跑，不能套用旧版本测量结论。
- 会议页显示的是 Windows 默认通信麦克风状态，不保证与每个会议软件内部选择的设备/静音完全一致。
- 开发验证未执行实际内存清理、录音或操作个人剪贴板。清理确认和权限链路虽已接入，本轮没有验证真实清理收益。

## 建议先验这五组

1. 设置：最小/最大/还原，监测项切换、数值编辑、颜色和透明度；看组件是否统一，中文是否清晰。
2. 宠物：反复移入/移出，一级/二级展开、四边拖动、锁定后收起，再恢复完整视图；注意黑边、裁切、无法点击或卡顿。
3. 办公：创建一条测试便签和一个短期测试待办，编辑/完成/延期；关闭设置后检查计时和提醒仍有效。
4. 截图：在你主动选择的内容上试四种模式；取消、批注/撤销、保存、粘贴及贴图关闭。
5. 报告和会议：生成并预览报告，检查脱敏；设置短会议计时，检查到时提示及麦克风未知/失败反馈。
6. 剪贴板：打开页面时应显示未记录；手动开始后复制自行选择的测试文字/图片，检查搜索、固定、原图粘贴、删除取消/确认。暂停应保留历史；关闭页面仍继续记录，退出应用才清空工具历史，系统当前剪贴板不因退出或清空历史而改变。

反馈请记录“页面/模式、操作步骤、预期、实际”，有条件附截图和屏幕缩放比例。测试内容无需发出个人报告、便签、录音或剪贴板内容。
