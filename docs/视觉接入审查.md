## 已发现与处理

1. 旧列表标题宽度与行内流式布局不同，实际阈值列错位。改为共享列宽及受约束子 UI，回归检查实际绘制位置和排序图标边界。
2. 生成控制图集带高透明噪点，重新生成后仍有边缘杂质。构建时仅对控制图标提取连通主体，保留分离的暂停条和抗锯齿；运行素材透明边缘不合格会阻断构建。失败原图只归档，不打包。
3. 快速拖动时原鼠标命中可能在绘制前离开边缘。加入按下起点回归后，实机仍收到 BeginResize 却没有缩放；不能把输入命令测试称为现场完成。增加 Windows 同步 WM_NCHITTEST 处理，实机右边和底边可缩至 840×600。异步框架命令时序是推断，未宣称已完整定位框架内部问题。
4. 小窗口导航最后一项覆盖底部状态。行高按可用高度缩紧；实际绘制回归检查末项与页脚间距，随后复核真实小窗口。
5. 首轮右侧预览说明被截断。减少说明、扣除固定空间并约束右列滚动。完整与精简选择卡原为空图形，改为已有采样的真实两行缩略预览；宠物使用真实选定形象。
