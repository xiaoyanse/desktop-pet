# 视觉纠偏审查（2026-10-12）

基线为 `4448093`，审查覆盖本轮源代码、构建脚本、新素材清单和实际调用方。改动超过 20 文件，按素材构建、UI、Windows 三组检查。未调用第三方审查应用；项目没有 `.Codex/memory/patterns/`，不声称检查不存在的规则。

## 已发现与处理

1. 旧列表标题宽度与行内流式布局不同，实际阈值列错位。改为共享列宽及受约束子 UI，回归检查实际绘制位置和排序图标边界。
2. 生成控制图集带高透明噪点，重新生成后仍有边缘杂质。构建时仅对控制图标提取连通主体，保留分离的暂停条和抗锯齿；运行素材透明边缘不合格会阻断构建。失败原图只归档，不打包。
3. 快速拖动时原鼠标命中可能在绘制前离开边缘。加入按下起点回归后，实机仍收到 BeginResize 却没有缩放；不能把输入命令测试称为现场完成。增加 Windows 同步 WM_NCHITTEST 处理，实机右边和底边可缩至 840×600。异步框架命令时序是推断，未宣称已完整定位框架内部问题。
4. 小窗口导航最后一项覆盖底部状态。行高按可用高度缩紧；实际绘制回归检查末项与页脚间距，随后复核真实小窗口。
5. 首轮右侧预览说明被截断。减少说明、扣除固定空间并约束右列滚动。完整与精简选择卡原为空图形，改为已有采样的真实两行缩略预览；宠物使用真实选定形象。

## 三组结论

- **正确性**：图集比例边界、空单元/重复名/未知目录、透明边缘及 3 MiB 运行预算在构建阶段检查；切图、alpha 缩放、纹理缓存、菜单图标区分及真实 GDI 混合有回归。模式切换仍改变真实配置，没有造新功能入口。
- **安全性**：新窗口附着检查进程 PID；不修改其他应用，不运行清理、不增加隐式录音、截图或剪贴板后台采集。原清理确认、命名管道和权限流程未变。
- **资源生命周期**：egui 纹理按需缓存；关闭设置释放背景。GDI 缓存随菜单关闭释放，位图/DC 在失败路径及 Drop 清理；选入对象先还原再释放。原图解码仅在构建及测试依赖，不进入生产依赖。
- **可维护性**：素材目录位于中性 assets 模块，UI 和 Windows 可共同使用；平台命中、GDI 绘制不放入 UI。递归架构测试覆盖新增模块。全部 Rust 源文件小于 500 行，切图脚本小于 400 行。
