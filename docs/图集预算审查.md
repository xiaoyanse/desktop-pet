# 图集预算审查

2026-10-12；比较基线main/8e3d82d，审查根及即时子视口、入口装配、开发观察器、只读驻留工具与对应回归。正确性、安全性、可维护性、性能四项均检查；源码检查通过不等于100 MB验收通过。

## 正确性

字体上限仅降低，不提高硬件较小上限；没有丢弃中文字体或改变字号。直接重建图集曾使12号字行高差1像素，准确Vec2布局回归先失败，保留框架样式字体缓存插入顺序后通过。根raw_input_hook和即时子on_begin_pass共同覆盖，缩放上下文回归仍不冒充实际多屏走查。

观察器仅元数据，不克隆FontImage或图片；退出纹理manager锁后读取字体Context，获取style/options后才进入fonts闭包。文件write失败停止记录，测量失败字段明确，不能拿缺失行当零占用。独立工作集工具处理零页、返回长度与缓冲上限；地址布局变动报错，驻留查询不是原子分配栈。

## 安全性

开发观察器和驻留工具不覆盖已有文件；工具先核实目标EXE，错误来源和覆盖实际拒绝并保留旧证据。只输出映射文件名/类别与数量，不读取页面内容或输出地址、完整来源路径。无用户配置迁移、第三方应用、外部发送、真实清理或不相关进程操作。

## 可维护性

bootstrap作为入口组合支持模块，不在UI/领域中添加平台/文件依赖，原架构禁止边界测试通过。生产主协调文件未超过500行。独立工具inspect函数包含目标核实、页查询、区域分类（超过50行的审查提示）：限定64位开发用途，单一取证流程、RAII释放句柄、有界查询与失败拒绝；后续扩展分配栈前再按能力拆开，现阶段不引入生产模块泛化。项目未有 `.Codex/memory/patterns`，未声称检查了不存在的Pattern文件。

## 性能与未完成项

单张设置字体纹理4 MiB→0.5 MiB已实测；102项回归、严格lint与release通过。探针默认关闭，开发模式最多120条/每秒一条，没有常驻像素副本。现场默认/最大设置和报告/原文显示有证据，所示诊断截图视觉复核未见新增P1/P2。
