# 桌面工作助理 0.2.1

本次补齐 Windows 安装包、真正的增量更新包和全量更新包。

- 首次使用：下载 DesktopMeter-0.2.1-setup-win-x64.exe，中文安装向导支持选择安装目录、快捷方式与卸载。
- 全量更新/便携使用：DesktopMeter-0.2.1-win-x64.zip。
- 精确基线差分：DesktopMeter-0.2.1-from-0.2.0-delta-win-x64.zip。由更新器校验与重建，不能直接解压覆盖。
- 新更新器会同时校验旧程序版本与 SHA256，匹配时优先使用更小的增量；不匹配或失败自动使用全量。
- 保存设置、旧版备份、新版启动确认与失败恢复机制保持有效；个人数据不放进更新包。

0.2.0 没有增量解码器，到 0.2.1 的首次在线升级使用全量；0.2.1 起支持后续增量更新。
0.1.0 没有在线更新功能，首次请使用安装包。安装或手动换版前正常退出旧实例。
安装包未做代码签名。本版本仍为阶段测试版，完整 GUI 自更新及多屏日常场景继续待现场验收。
没有恢复后台自主任务，也没有新增录音等已暂停需求。
