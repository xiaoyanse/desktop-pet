# 桌面工作助理 0.2.0

本版本在已有宠物直接截图与会议操作基础上增加纯 Rust 在线更新。

- 在常规设置或托盘检查更新；GitHub / Gitee 双来源，无需登录和授权码。
- 启动后只自动检查；下载、安装由用户操作，支持取消、忽略版本和固定版本。
- 校验包大小、SHA256、ZIP 路径、内部版本与程序 SHA256。
- 保存设置后安装，或安排下次正常启动安装；启动确认失败恢复原版，保留旧版备份。
- 有额外文件的应用目录拒绝替换，个人配置、便签及图片数据目录不搬动。

Windows x64：下载 DesktopMeter-0.2.0-win-x64.zip 并解压到独立目录。
先退出旧版，再运行 desktop-meter.exe；启动设置.cmd 可直接进入工作台。
0.1.0 没有更新器，首次需要手动换成此版本，此后的发布版本可通过软件检查。

这是阶段验证版。当前代码检查、原生合成预览及隔离更新替换/回退已验证，
不代表所有功能、多屏 DPI、动画和完整 GUI 更新场景都已获用户现场验收。
工作区启动器、手动录音和回溯胶囊继续保留为待开发，后台自主推进仍暂停。
