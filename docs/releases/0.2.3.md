# 桌面工作助理 0.2.3

修复从桌面快捷方式或程序目录启动后，在线更新报“原程序目录被占用或没有写入权限”的问题。
原因是更新辅助进程继承了原程序目录，自己占住了待备份的目录。
现在启动辅助进程时指定暂存工作目录，辅助进程也主动离开程序目录，再等待原程序退出并替换。
失败时在本地更新任务目录保存具体错误；外部占用时保持原程序与下载文件，不强制结束其他软件。

保留 0.2.2 的顶部布局、圆角、截图自动复制和 Windows 品牌图标修复。

- Windows 安装包：DesktopMeter-0.2.3-setup-win-x64.exe。
- 全量更新包：DesktopMeter-0.2.3-win-x64.zip。
- 0.2.2 精确基线增量包：DesktopMeter-0.2.3-from-0.2.2-delta-win-x64.zip。
- update-manifest.json 用于在线校验及自动选择增量/全量。

旧版 0.2.1/0.2.2 的更新器已经在旧程序中，下载新版不能提前修复旧辅助进程。
若旧版已出现上述错误，先关闭错误提示，使用安装包完成一次修复升级，
或先正常退出，再通过位于程序目录之外的工作目录启动旧程序后检查更新。
不要直接解压增量包覆盖程序，也不要删除个人数据或 previous 备份。

个人配置与便签路径保持不变，不接授权；安装包暂未签名。
后台任务和其他已暂停需求没有恢复。本补丁不自动替换用户正在运行的 0.2.2。
