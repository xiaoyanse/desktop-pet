# 桌面工作助理 0.2.2

本次修复四项日常界面与截图体验：

- 压缩工作台顶部留白、页标题和导航品牌区，给内容区留出更多空间。
- 设置窗口的原生轮廓与绘制圆角一致，去掉圆角外的黑角；缩放和调整尺寸时同步，最大化时恢复方形。
- 四种截图完成后自动复制到系统剪贴板，不再自动打开工作台。Esc 取消保留原剪贴板；已主动打开截图页时保留批注预览。复制失败保留截图供手动重试。
- 补齐设置窗口、EXE、安装包及快捷方式的星球品牌图标，包含 16–256 像素六个尺寸。

首次安装：DesktopMeter-0.2.2-setup-win-x64.exe。
