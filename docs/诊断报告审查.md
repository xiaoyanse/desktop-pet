# 诊断报告阶段审查

基线 `a847c0b`，本地待保存阶段：脱敏资源与进程报告。新功能跨越五层，超过 20 个文件，按以下四组读取上下文及修改审查；不调用第三方 AI、CodeGraph 或 AI Mailbox。当前代码仍与用户清理、计时、设备和外观配置兼容。

## 分组与证据

1. 领域与接口：`domain/report`、`interfaces/report`。SafePath 私有字符串只允许脱敏构造；用户名、自定义项目目录、UNC 主机/共享不进入预览。Markdown 单元格过滤控制字符、长度限制、转义分隔符与 HTML；缺失数据不伪造零。启动参数、环境、命令历史不采集。AppData/系统安装目录结构和可执行文件名仍保留，报告不是完全匿名。
2. 应用生命周期：`application/report` 及装配。限制单任务；取消、异常、通道断开与线程创建失败保留旧预览。保存使用冻结文本；完成后回收工作线程。审查发现取消与已入队 Generated 竞争，tick 再次检查取消，避免取消后覆盖预览。模拟后端验证单飞、取消及保存失败，不调用真实清理。
3. Windows 与存储：进程句柄 RAII，CPU 差分及路径查询检查创建时间；父进程要求创建时间不晚于子进程，否则未知。路径仅查询所选前五/运行时的联合集合并按 PID 缓存，最多保留 512 项。日常保存 create_new，不覆盖历史文件；写入失败明确可能留下不完整文件，不报成功。开发 report-probe 的指定路径覆盖策略另行文档，不混同日常保存。
4. UI、图片与入口：固定操作区、独立滚动、20 项分页、只读原文、复制冻结文本；设置与螺旋复用同一服务，打开不采集。页面拆入口/操作/预览，集成测试留在 settings/tests，不暴露生产私有模块。复用报告/剪贴板图片，专用保存图片和完整提示词落盘；无运行时图像解码器、Node/Python 或新依赖。

## 发现及处理

- 警告，布局：概览继承 horizontal 后标签/值挤在一行，改为 top_down；子区域仍按最小内容收缩，实际四列挤左，补最小列宽。初始测试只检查主操作可见，未拦住数据布局；现检查四组标签/数值分行及首末数值横向间距，缺陷能先复现再通过。
- 警告，失败状态：直接 spawn/join 不能保证线程启动失败或任务 panic 时 UI 仍可用；使用 Builder 返回值与 catch_unwind，通道断开有明确错误。退出时请求取消并回收；实际原生 API 等待时间没有严格上界，不把约两秒当截止保证。
- 警告，取消竞争：取消可能晚于工作线程排入结果，应用接收端亦检查标志。 gated 模拟后端验证旧预览不被取消结果替换；不把假后端测试当实机取消按钮验收。
- 建议，保存图标：视觉复核发现勾选语义接近确认，改成专用玻璃软盘图片，替换仅限保存。最终切图及真实页面另见《本轮验证》。

未发现阻断此本地保存阶段的致命问题。上述布局、错误态、取消竞争和图标问题已经处理，代码/输入/存储回归与发布构建证据见《本轮验证》。不代表全系统诊断、长期资源稳定或用户视觉验收。
