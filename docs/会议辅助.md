# 会议辅助

2026-10-12，接续已选的“会议控制：计时、静音提醒和麦克风状态”。阶段二十正在实现；沿用基础组件，不另造按钮或控件主题。功能验收与提交结果登记在《本轮验证》，不以本文代替实测。

## 产品与数据边界

手动开始会议，提供15/30/60分钟及自定义1–1440分钟。暂停不计时，恢复继续，结束保留本次时长，清除回到未开始。到时只提醒一次，会议继续计时并显示超时。关闭设置不结束会议；退出整个应用结束，暂不保存会话历史。配置保存沿用现有设置存储。

默认采用入口标记提醒，另可选择静默或不抢焦点的提醒卡片。检查静音默认关闭，用户开启后按1–120分钟间隔检查；仅在新鲜状态确认为未静音时提醒，同类未处理提醒不重复堆积。长时间挂起后不补发历史提醒。会议开始时冻结时长与检查间隔，提醒强度可即时切换。

系统默认通信输入端点的名称、静音状态和输入音量每2秒按需读取。只有会议运行或页面可见时查询，暂停且页面关闭后停止。缺失设备、权限或读取错误直接显示失败；未知音量不能伪装成0%。系统端点状态不等于会议软件内部静音；会议软件使用其他设备时需要在该软件核对。

只调用Core Audio元数据与音量状态读取接口，不获取音频样本、不打开录音流、不改静音或音量、不切换设备。应用/接口/Windows适配器分层；最多一个短生命周期后台查询任务，界面线程不等待设备读取。退出等待已有查询任务释放COM；异常驱动导致COM调用长时间阻塞仍是边界，不能宣称任意设备环境都即时退出。

## 验证计划

- 领域/应用：暂停恢复、超时只提醒一次、间隔无补发、未知/错误状态、默认不查询、查询节流与静默关闭。
- 界面：真实框架点击开始/暂停/继续/结束/清除；生产组件的正常/未知/失败状态；小窗口导航和螺旋入口四角/动画边界。
- 原生：生产组件加合成数据输出自身窗口缓冲；可另用显式只读探针读取真实端点状态，不录音、不操作会议软件。
- 现场：与用户会议软件选中设备比较、设备切换/断开、多屏DPI和日常提醒仍需现场验收，不从合成图片推定已通过。
