## H07 修正与实机证据

新增不可见、测试独占的 Win32 窗口回归：创建在左侧 -55px、再次移出左侧和右下侧后调用真实修正函数，校验窗口始终在最近工作区且未显示。旧测试仅检查命中区/几何，漏掉设置窗口还原生命周期；该用例补真实原生矩形，实机操作补实际子类接线。测试本身没有安装子类或发出还原命令，不能替代实机。初版测试引入 GetWindowSubclass 导致测试环境入口点缺失，改用 user32 窗口属性后完整测试及实际发布版启动通过，未保留失败导入。

当前 H07 仅以本机上述场景验证；多屏、不同 DPI、拔插显示器和全部 Windows 配置仍待覆盖。

## 渲染格式假设排除

开发探针仅在显式参数下读取 CreationContext 的当前根 GL 上下文。使用默认 framebuffer 附件查询，记录完整 queryError，未用不适用的旧 DEPTH_BITS 查询。`render-root-format-20261012.jsonl` 的 PID39716 实际结果：Intel Arc 140T、OpenGL3.3，默认 framebuffer=true，双缓冲=true，颜色红通道8位、alpha8位，depth0、stencil0、samples0、queryError0。未误开额外深度/模板/MSAA 的假设在该根上下文被排除。

这些值不证明系统交换链实际副本数量、所有子窗口格式或驱动内部内存，更不证明驱动泄漏。独立驻留工具追加最多64个自身窗口的客户区/原生像素格式元数据，不输出标题、地址或内容；GetPixelFormat 返回0时输出 unknown。`render-format-default-v2.tsv` 是重新编译后的有效证据；初次旧工具输出及编译失败时遗留可执行文件的结果不作为格式判断依据。字段未知不能解释成无缓冲。
