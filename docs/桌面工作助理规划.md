# 桌面工作助理：采访结果与实施顺序

日期：2026-10-12。本文记录用户选择，不代表全部功能已经实现。持续自主推进和阶段本地提交的授权仍有效；用户喊停时暂停。

全部要求、建议池及当前实施状态统一汇总于 [需求总表](需求总表.md)；这里保留采访细节。当前加入目录层内归组及生成视觉资产接入，先于螺旋和办公工具实施。

## 已确定的方向

产品以桌面宠物为主要入口，资源监测作为基础能力。界面统一使用现代原生 Rust 绘制，不引入 WebView、Node.js 或 Python 运行环境。新功能按需启动，不为每个工具增加常驻采集线程。

用户明确要求设置窗口取消系统标题栏及默认边框。自绘窗口保留拖动、八方向缩放、最小化、最大化/还原与关闭；关闭设置不退出监测器。页签、列表、记录表格统一选中、悬停、禁用、空态及间距。

## 螺旋组件与交互

- 宠物保持现有小尺寸；展开内容使用独立透明工具窗口，不占任务栏，不把整个矩形空白区域拦成鼠标障碍。
- 一级按约 250 毫秒顺序展开“资源 / 办公 / 工具”；二级只显示当前分类。不会同时铺开全部功能。
- 资源分支包含资源摘要、完整监测视图、清理及报告。摘要显示数值；清理展示档位和明确确认入口，悬停不会执行清理。
- 办公分支包含计时圆环、便签、会议控制。计时组件直接显示剩余/已用时间及运行、暂停状态。
- 工具分支包含截图、剪贴板、工作区及设置。各组件根据用途呈现简短数据或状态，而不是重复相同的单一按钮。
- 根据显示器工作区和宠物位置选择展开方向，保证组件在屏幕内；考虑负坐标、缩放、贴边和模式切换。
- 鼠标从宠物沿轨迹进入组件时保持展开；离开整体区域约 350 毫秒后收起。分类切换保留短暂意图延迟，避免路过就切换。
- 动画期间按需刷新，结束后停止动画刷新；禁用动画时立即展开/收起。保留托盘、双击恢复与键盘可达入口。

1. 完成并提交无边框设置、页签/列表/表格与即时预览。
   该交互基础已提交为 `694d2d5`；最终视觉尚未验收。继续合理目录分级，然后切图接入与全应用风格改版，保留完整提示词、来源及素材版本。
2. 实现分层螺旋的状态机、屏幕边界及可操作组件，接入已有监测、设置、清理入口。未实现功能不放可点击假按钮。
3. 加入计时与诊断报告，并接入相应螺旋组件。
4. 截图、批注及贴图，然后便签、会议控制。
5. 剪贴板历史与工作区入口；按实际使用继续调整顺序和交互。
6. 手动录音、确定语义后的时间胶囊录音，以及待办管理/提醒。录音默认不启动，后台回溯需要明确开启，不在开发验收时录制用户环境。

用户进一步要求灵活使用 AI 图片生成及切图，重新建立全应用的视觉品质。保存每次提示词、来源、切图规则和版本，后续补图按同一风格扩展；不得使用文字符号充当占位图标。生成参考图与实际可操作界面区分，已生成图集需验证 alpha、切片完整性和小尺寸可读性。
