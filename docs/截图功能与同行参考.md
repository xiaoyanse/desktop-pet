# 截图：功能范围、同行参考与验收

更新：2026-10-12。用户最新要求：截图需支持全屏、自由形状、矩形区域、窗口及自动识别窗口；自行研究成熟截图工具，参考微信的短操作链。以下是执行契约，不是已完成功能声明。

## 本轮实现范围

1. 全屏：整个虚拟桌面，包括负坐标的副屏；大图明确容量限制，不静默截断。
2. 矩形区域：任意方向框选，确认前可重新框选、方向键微调、Shift＋方向键调整大小，Enter 确认、Esc 取消。
3. 自由形状：按住鼠标划出轮廓，自动闭合；轮廓外透明，保存及复制保留透明度。它不同于矩形截图之后画线。
4. 窗口：鼠标悬停高亮可见窗口，点击选定、Enter 确认；排除本工具自己的窗口，窗口消失或变化须报错。首版捕获可见桌面中的窗口范围，遮挡内容不会声称已恢复。
5. 编辑：矩形、箭头、画笔、不透明遮挡；撤销、重做；原图保留，复制、保存和贴图使用同一份批注结果。
6. 输出：复制图片、保存 PNG、自定义绝对路径目录、置顶贴图；可关闭贴图，关闭编辑器释放图像。

追加候选：椭圆、直线、文字、编号、荧光笔、像素放大镜、最近选区、延时截图、显示器选择。滚动长截图、OCR、录屏分别有独立生命周期和验收，不能用普通截图的代码冒充支持。本轮优先闭环上述六项，再按实际收益扩展。

## 架构决策

全部 Rust：领域保存选区/图像/批注；应用服务管理单任务和取消；接口定义捕获与输出；Windows 层负责原生选区、窗口识别、GDI 与剪贴板；UI 分为入口、编辑器和贴图。PNG 本地编码，不调用微信、系统截图工具或第三方程序。

按需创建截图线程，不常驻捕获，不自动写入剪贴板，不上传。开发测试只用人工像素、内存 DC 和本工具合成窗口；实际桌面截图只有用户主动点击产品按钮后触发。选区与截图期间隐藏本工具入口，恢复时不更改监测配置。图片上限有界，原图共享，批注有数量/点数限制，关闭后释放纹理。
