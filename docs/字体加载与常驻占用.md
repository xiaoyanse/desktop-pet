# 字体加载与常驻占用

阶段基线 `2391920`。本轮针对监视器自身的常驻资源，不清理系统缓存、裁剪字符或修改用户的采样/宠物设置。

## 来源与实现

本机当前 `msyh.ttc` 大小 19,704,352 字节。旧 Windows 适配器读取完整 Vec，UI 以 FontData::from_owned 传给 egui。已安装的 epaint 0.31.1 在 `ab_glyph_font_from_font_data` 中对 Owned 字节使用 FontVec 并 clone，Borrowed 则使用 FontRef；每个缩放对应的 Fonts 实例都可能有独立解析副本。单凭源码和文件大小只能确认复制来源，不能推算整个进程节省量。

Windows `fonts` 模块优先打开系统字体并使用 PAGE_READONLY / FILE_MAP_READ 映射，保留只读文件句柄，禁止写共享以防字节在借用期间被写入/截断；允许读共享和原子替换所需的删除共享。字体只读，不修改文件、注册表或字体优先级。映射与读取候选仍为微软雅黑、黑体、宋体；只接受非空、普通、至多 64 MiB 的文件。

OnceLock 只缓存一个候选 backing 至进程退出；映射失败回退读取一份自有缓冲。两者均由稳定生命周期 backing 产生静态借用，UI 的 FontData::from_static 保留该借用，避免框架复制。临时映射通过 RAII 释放，静态映射由进程退出回收；退出前不卸载仍被字体布局使用的地址。没有用非静态局部缓冲伪造 static，也没有新增手写 Send/Sync。

UI 字体族配置仍为比例字体优先使用系统中文字体，等宽字体在内置等宽字体之后追加中文；保持原字形、尺寸、TTC 索引和回退。系统缺少候选字体时继续提示安装字体，不将缺字当作性能收益。没有裁切中文范围、图标或图片。

## 回归与口径

- 独立临时文件检查真实原生映射为 MEM_MAPPED、PAGE_READONLY，读取一致，持有期间写入被拒，释放后文件重新可写；仅删除测试自建文件。
- 重复系统字体请求必须借用同一地址；跨层回归进一步检查实际传入 egui 的字体仍为 Borrowed、指针一致，防止中间一步 into_owned 再引入复制。
- 100/125/150/200% 字体上下文核实实际 pixels_per_point、中文标题和等宽正文的字形覆盖及逻辑布局宽度；不把字体上下文测试当作多显示器窗口现场验收。无系统中文字体的机器跳过字形检查，本机已实际存在并通过。
- 冷启动对比保持个人配置和命令一致，只显示桌面宠物、不先打开设置/报告；两版各采样三分钟，不把上一阶段的热态报告场景拿来作前后基线。工作集含文件映射和共享页；私有内存另列，不能把映射文件大小当物理常驻占用。

最终实测、设置页面/报告中文走查及提交见《本轮验证》。CPU 和长期稳定不因一次短期内存对比自动获得结论；后续仍需评估设置/多缩放/长时间运行下的缓存与宿主开销。

## 开发检查工具

`scripts/inspect-font-mapping.rs` 是独立的 64 位 Windows 开发工具，不编入产品、不增加常驻线程。可用 `rustc --edition 2024 -D warnings scripts/inspect-font-mapping.rs -o evidence/inspect-font-mapping.exe` 编译，参数依次为 PID、预期项目可执行路径、证据输出文件。输出文件由调用者指定，会覆盖同名文件，因此仅使用自建 evidence 路径。

工具先核实目标可执行路径，再只读查询地址空间；仅输出四种候选字体的名称、映射大小和只读标记，不输出其他映射路径、不读取页面内容。查询次数和地址前进均有限制，异常返回失败；错误可执行路径实际拒绝且不创建输出文件。原生 GUI 的映射证据可确认已使用只读文件视图，不能单凭此证明整个进程没有其他字体副本或长期泄漏。

## 字形图集预算（2026-10-12）

图集宽度上限2048，同时尊重硬件更小上限；根视口raw_input_hook和即时子视口on_begin_pass共同覆盖。未改字体族、字号、中文范围或只读backing。设置页实测16384×64改为2048×64，对应单张逻辑纹理由4 MiB降为0.5 MiB，不等于全应用减少3.5 MiB，更不能证明启动峰值低于100 MB。

框架在on_begin_pass之前已初始化字体，重建后须保留原样式字体缓存插入顺序。epaint缓存按取整像素字号复用，直接跳过该顺序曾使12号字行高差1像素；四缩放、两字体族、三字号和根/即时子上下文准确布局回归已拦住并修正。获取scale/style/options后才进入fonts锁，禁止嵌套Context锁。当前也没有缓存全套中文字形，仍按需栅格化。现场截图及尚未解决的峰值见《内存分配取证》。
