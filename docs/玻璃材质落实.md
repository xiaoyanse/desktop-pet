# 工作台玻璃材质落实

基线 `f8102e6`。用户指出真实界面与设计图差异过大；前两轮虽然改善比例和背景，但侧栏仍混用金属芯片、卡通猫头像与绿色文档，卡片只有平面描边。本阶段统一真实图标系统和玻璃面层，不把新的概念图当作运行结果。

## 当前接线

内置 image_gen 生成 `assets/visual/atlases/navigation-glass-v1.png`，完整提示词保存到对应 prompts 文档。八格顺序为监测、宠物、设备、常规、清理、历史、计时、报告，统一烟蓝玻璃圆形底座与珍珠银符号。按现有 Rust 构建切图、alpha 连通提取和抗锯齿缩放规则处理，不修改原图；旧图集继续保留但这八格移出运行清单。

UI Icon 映射和原生菜单共同使用新目录，保留动作、排序和提示。无文字符号占位、运行时解码或下载。运行对象数量仍为 40、RGBA 字节仍为 2,703,360；静态素材量不能替代进程开销实测。

新增 `ui/common/glass` 共享绘制，设置卡片保留原 Frame 的布局和操作返回值。先预留绘制槽，内容布局后填写圆角渐变与内侧描边，使装饰实际位于文字和控件后面。颜色在预乘线性 RGBA 中插值，再转换为框架 Color32；每个渐变 29 个顶点，不增加持续动画、定时器或采样线程。透明圆角边界由几何限定，不在直角矩形上硬裁图片。

侧栏选中项、模式卡与主/次操作统一光照及描边；选中为香槟，悬停为中性银白。资源绿黄红阈值、用户监测主题色和宠物形象不变。主按钮保持原有大面积和明确文字，禁用时不绘制强调层。

第一次发布实机显示过亮浅灰面板；from_white_alpha 的框架转换与整张渐变叠加达到了不符合参考的强度。现限制面层端点的实际预乘颜色，保持深蓝底，并在绘制回归中约束面层 RGB 的上限。该断言只拦截大面积高亮覆盖，不能替代实际混合后的显示判断。

## 缺口与验证口径

原测试检查文字可见、列宽、图标存在和 alpha 边缘，没有判断图标是否同一材质或是否接近用户参考。此次补绘制顺序/几何边界回归并检查真实发布界面，图片仍须由实际小尺寸与视觉判读核验，不能以测试绿色代替用户审美接受。

构建接触表原先固定 640×480，超过 48 个开发切片时末行会裁切；现按实际图标数分配高度，让未接入的开发素材也可查。修复只影响构建证据，不增加产品绘制。

构建小尺寸判读确认八种主体在 32 像素可辨，20 像素的历史/秒表差别减弱；保留并实际检查导航文字，不设置仅图标导航。原图外围有青蓝散点，Rust 提取后须在真实界面确认无同类污染，不以原图或清单 quality 字段单独证明视觉无问题。

本阶段保留静态背景方案，没有读取用户桌面实时模糊。宠物继续使用原有动画图集，不擅自替换用户选择的形象。日常非激活螺旋、多屏 DPI、长时开销及截图/办公工具仍按需求总表跟踪，不因材质改版标为完成。最终实机、资源证据、复核范围与阶段提交记录见《本轮验证》《自主推进》。
