# 分层螺旋入口

本阶段落实用户选择的“资源 / 办公 / 工具”两级入口，替换旧纵向快捷看板。三类使用已保存提示词对应的六张 AI 玻璃组件图；按顺序旋出、轻微回弹，约 250 毫秒结束，静止时不维持动画刷新。关闭宠物动画后立即绘制最终位置。

## 交互与实际功能

- 悬停宠物或快捷清理入口，先出现三个分类；分类悬停约 120 毫秒后展开，点击立即展开。只展示当前分类的二级功能。
- 资源：按现有启用项显示前两项实时读数及颜色；清理展示当前档位/清单数量，先检查并确认冻结清单；另有轻度一次快捷确认及完整清理中心入口。完整/精简视图可恢复切换。
- 办公：显示实际计时阶段、剩余/已用时长及状态；直接开始、暂停、继续或开始休息，详细按钮打开计时页；便签、待办与会议辅助分别打开对应页面，便签卡右上角剪贴板图标打开历史页，不会自动启用记录。
- 工具：三个独立卡片分别打开资源诊断报告、截图与贴图、设置工作台。截图卡明确列出全屏、区域、自由、窗口四种模式；点击先打开屏幕工具页，由用户选择模式后启动截图。打开报告不自动采集。录音、时间胶囊和工作区启动器仍未实现，没有伪入口。
- 所有页面入口共用单次唤起请求：显示窗口、退出最小化并请求焦点；日常重绘不重复抢焦点。设置、托盘和启动设置请求复用同一机制。
- 可保持展开，或离开所有组件约 350 毫秒后收起；经过空隙后再进入会取消收起。关闭后不会在同一次宠物悬停中立即弹回。Esc 可收起。
- 外观页提供“试用螺旋快捷入口”。试用复用同一渲染和功能，保持展开，显示普通设置类窗口以便检查；关闭设置同时收起试用。日常入口依旧为非激活透明工具窗口，不占任务栏。

## 边界与资源

领域层 `domain/companion/spiral.rs` 维护意图延迟、收起和布局。依据宠物所在显示器的工作区选择左右方向及上下镜像，整窗限定在工作区；负坐标和工作区尺寸由已有桌面接口传入，不假设主屏为零点。

UI 位于 `ui/companion/flyout/`：入口协调、统一渲染、各功能组件、输入回归分开。Windows `quick_regions` 使用圆形与圆角区域的并集，将透明空隙排除在窗口区域之外；按窗口 DPI 转换坐标，仅附着当前 PID。相同区域不重复设置，系统接管成功后的区域句柄，临时句柄由 RAII 释放。设置失败时收起入口并显示错误，避免静默留下整块遮挡。

运行素材新增六张 128×128 切片共 393,216 字节；无新采集线程。宠物可操作状态每 200ms 读取原生光标，即使关闭外观动画也能触发悬停；入口展开时以最多 50ms 检查鼠标和收起，动画期间约 16ms 刷新。入口关闭后不保留 50ms 检查。资源与计时复用现有服务，实际开销另行记录。

2026-10-12 用户追加反馈后修正生命周期：移出检测在缺少布局、未创建快捷窗时也会解除“关闭后禁止重弹”；固定与穿透统一清除快捷窗、清理确认、保持展开及悬浮提示，固定时不绘制操作栏，通过托盘/热键恢复。一级、二级轨迹先在相同坐标中计算再统一镜像；二级只作 24px 受限弧线、顺序淡入，避免大卡片从分类中心穿过其他分类；动画中不触发工作操作。

原生区域在动画期间保持绘制包络，不逐帧移动裁剪；稳定后恢复离散区域。为避免硬裁切，分类保留完整图像范围，卡片不绘制超出区域的阴影。实机首版仍发现黑圈，继续修正全客户区 DWM 合成，结果在《交互问题与性能门禁》《本轮验证》登记，不只凭透明 RGBA/单测判定视觉完成。动画约 250ms 内包络中的透明空隙可能参与窗口命中，稳定后排除；不称所有时刻透明空隙都穿透。

## 验证状态

布局、意图延迟、跨空隙保持、关闭不重弹、当前清单/轻度确认与取消、计时直接控制有回归。GDI 真实区域测试检查离散组件之间的点被排除。构建、实机与视觉证据见《本轮验证》，没有执行实际清理。

试用截图与日常工具窗口样式分开登记；试用不证明所有桌面悬停/DPI/多屏组合。界面仍依据实际运行继续打磨，未宣称整个工具的最终视觉验收。

2026-10-12 阶段二十四修正宠物工具入口：旧测试未点击截图入口，也没有检查已存在的最小化设置窗口。新增截图四角真实 egui 按下/释放→生产路由、所有页面路由和一次还原窗口命令回归。当前运行旧版的只读探针确认设置 minimized=true，旧版 --settings 请求后仍为 true；新测试修前缺少 Minimized(false) 指令而失败，修后通过。Computer Use 无法激活该窗口，未把自动测试当作日常宠物悬停现场验收。详见《宠物工具入口修复》。
