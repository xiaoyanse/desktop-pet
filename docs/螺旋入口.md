# 分层螺旋入口

本阶段落实用户选择的“资源 / 办公 / 工具”两级入口，替换旧纵向快捷看板。三类使用已保存提示词对应的六张 AI 玻璃组件图；按顺序旋出、轻微回弹，约 250 毫秒结束，静止时不维持动画刷新。关闭宠物动画后立即绘制最终位置。

## 交互与实际功能

- 悬停宠物或快捷清理入口，先出现三个分类；分类悬停约 120 毫秒后展开，点击立即展开。只展示当前分类的二级功能。
- 资源：按现有启用项显示前两项实时读数及颜色；清理展示当前档位/清单数量，先检查并确认冻结清单；另有轻度一次快捷确认及完整清理中心入口。完整/精简视图可恢复切换。
- 办公：显示实际计时阶段、剩余/已用时长及状态；直接开始、暂停、继续或开始休息，详细按钮打开计时页。
- 工具：分别打开资源诊断报告与设置工作台。打开报告不自动采集；截图、录音、待办等尚未实现，不放空操作。
- 可保持展开，或离开所有组件约 350 毫秒后收起；经过空隙后再进入会取消收起。关闭后不会在同一次宠物悬停中立即弹回。Esc 可收起。
- 外观页提供“试用螺旋快捷入口”。试用复用同一渲染和功能，保持展开，显示普通设置类窗口以便检查；关闭设置同时收起试用。日常入口依旧为非激活透明工具窗口，不占任务栏。

## 边界与资源

领域层 `domain/companion/spiral.rs` 维护意图延迟、收起和布局。依据宠物所在显示器的工作区选择左右方向及上下镜像，整窗限定在工作区；负坐标和工作区尺寸由已有桌面接口传入，不假设主屏为零点。

UI 位于 `ui/companion/flyout/`：入口协调、统一渲染、各功能组件、输入回归分开。Windows `quick_regions` 使用圆形与圆角区域的并集，将透明空隙排除在窗口区域之外；按窗口 DPI 转换坐标，仅附着当前 PID。相同区域不重复设置，系统接管成功后的区域句柄，临时句柄由 RAII 释放。设置失败时收起入口并显示错误，避免静默留下整块遮挡。

运行素材新增六张 128×128 切片共 393,216 字节；无新图片生成、依赖或采集线程。只有展开/切换动画、意图确认及待收起时刻额外请求刷新。资源与计时复用现有服务，实际开销另行记录。

## 验证状态

布局、意图延迟、跨空隙保持、关闭不重弹、当前清单/轻度确认与取消、计时直接控制有回归。GDI 真实区域测试检查离散组件之间的点被排除。构建、实机与视觉证据见《本轮验证》，没有执行实际清理。

试用截图与日常工具窗口样式分开登记；试用不证明所有桌面悬停/DPI/多屏组合。界面仍依据实际运行继续打磨，未宣称整个工具的最终视觉验收。
