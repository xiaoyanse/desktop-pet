# 清理档位与交互

## 推荐依据

这三个档位是本应用根据对正在进行工作的影响所作的产品建议，不是 Windows 的官方分级。清理项数量不是收益指标，不能保证释放特定容量。

| 档位 | 实际执行项 | 适用场景 |
| --- | --- | --- |
| 轻度，默认推荐 | 低优先级待机缓存 | 工作进行中，保留应用工作集；待机页本已属于可用内存，因此收益可能很小 |
| 中度 | 系统文件缓存、全部待机缓存 | 缓存整理；后续访问可能重新读取磁盘 |
| 重度 | 应用工作集、系统文件缓存、已修改页、全部待机缓存 | 工作告一段落后的临时缓解；可能引发调页、磁盘写入及停顿 |

轻度保留一项是有意选择，界面明确列出原因和实际包含项。中重度不再重复清低优先级待机页，因为全部待机缓存已经覆盖它。默认不纳入卷缓存刷新、注册表刷新及相同页合并：前两项侧重落盘，后一项效果依赖内存内容；这些接口仍在高级自定义中。

[Microsoft 工作集说明](https://learn.microsoft.com/en-us/windows/win32/memory/working-set)区分常驻页、软缺页和需磁盘读取的硬缺页，收缩工作集可能增加后续调页。[SetSystemFileCacheSize](https://learn.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-setsystemfilecachesize)提供清空文件缓存的参数，并指出过小缓存可能损害性能。[FlushFileBuffers](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-flushfilebuffers)的作用是把缓冲数据写到设备，不能等同于保证释放内存。

## 交互规则

- 清理中心先显示状态、三个档位与当前包含项，接着显示全宽 48 像素高的图标加文字主按钮。高级选择默认折叠，自动规则与历史保留。
- 快捷面板提供相同的大主按钮及确认流程；中重度入口进入完整清理中心。
- 点清理先固定本次清单，并滚动至确认区域，再点确认才提交任务；修改档位或自定义选择会取消旧确认，取消、关闭页面或快捷面板不执行。等待 Windows 授权或执行时禁用重复操作。
- 自动规则仍默认关闭。未明确允许敏感操作时，仅可执行低优先级待机清理及页合并；工作集、文件缓存、卷写入、注册表、全部待机和修改页均需要明确允许。界面展示经过过滤后的实际自动项目；无可执行项时不启动空任务。
- 本轮走查与测试只检查选择、取消、显示和请求模型，不实际清理系统。

## 旧测试未拦住的问题

旧测试只核对选项和任务状态，没有约束主操作尺寸与布局，也没有验证确认后修改选项的情形。新增回归要求主按钮全宽且高至少 48 像素、禁用时不可点击，并验证确认清单固定、取消不生成请求、空选择不生成请求、档位匹配与不重复包含低优先级页。实际 GUI 走查还需验证中文、布局和确认可达。
