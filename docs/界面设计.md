# 桌面仪表的界面语言

阶段二十二补齐数值组合、细轨道滑块和预设/RGB/HEX配色弹窗，外观与截图批注使用同一组件。输入、选择、开关、操作、状态、列表、确认和提示共用深蓝玻璃/玉绿/暖白规则；配色非法输入保留原值，父级禁用会收起弹窗。完整清单和中间失败见《组件体系补齐与验收》，原生候选截图见《本轮验证》。用户终版视觉认可仍单独保留。

2026-10-12 起以[基础组件设计](基础组件设计.md)约束跨页面控件。输入、选择、开关、按钮、数值、反馈、列表和弹窗必须复用共同主题；真实组件画廊与生产页面截图见《本轮验证》，不以AI设计图替代运行验收。

阶段二十会议页沿用共享卡片、全宽主操作、选项和状态标签，正常/静音、未静音/超时、不可读区分含义而不只变颜色。提醒卡片保留同样边框、圆角、主次操作和中文字体。父级禁用时图标与文字同时变化。11页实际原生输出已检查；这只是当前组件版本，终版视觉仍需用户认可，不能宣称所有图标材质与全部场景已经完美一致。

阶段二十一替换纯白控制图集，固定/还原/箭头/X/确认/加减/窗口操作/播放暂停统一烟蓝玻璃和玉绿边缘。图标不预绘按钮载体，使用共享状态表面；静止无需额外动画。12页实际输出包括16/20/24像素与禁用画廊，截图入口下方杂点已去除。设置、办公、提示和列表图标的主题协调改善，终版认可及全部DPI仍未通过用户验收。

定位是陪伴办公的桌面助理，资源监测仍是基础能力。悬浮入口保持小巧，设置工作台有清晰的信息层级和足够大的操作区域。

## 视觉依据与当前实现

以 `assets/visual/references/concept-v1.png` 为设计依据。用户指出第一版运行界面与设计图相差很大；仅换图标和背景不能视为落实设计。当前按真实功能重新调整构图，计时与分层螺旋已经接入；便签等未实现入口不放成空操作。

- 连续的烟蓝磨砂材质贯穿窗口、侧栏和内容，不使用黑色标题条及硬分割线。背景为静态生成图并压暗，半透明内容叠加其上；当前没有实时采集桌面或系统模糊。
- 品牌位于 228 像素侧栏，品牌字 22 像素，使用玻璃星球。材质贯穿侧栏顶部，不产生标题区硬切线。导航使用图片图标和中文名称，选中项用玻璃底色、圆角及香槟色轮廓区分。默认行高 60，小窗口自动缩紧，底部状态不覆盖最后一项。
- 页面标题 34 像素，说明 14，辅助信息主要使用 12。浅灰文字保持对比；香槟色标记选择状态，青绿作辅助。资源压力继续使用用户可配置的绿、黄、红规则。
- 监测分类合并为一条分段选择器；项目位于连续透明面板内，使用细分隔线。标题与实际开关、趋势、阈值及排序共享列宽，窄窗口仍对齐。
- 外观页使用完整卡片、精简视图、桌面宠物三张真实模式卡片。下面为独立滚动选项与即时预览；普通窗口放大宠物预览，小尺寸降低预览高度。桌面宠物仍保持 72×84。
- 无系统标题栏，窗口操作为圆形载体及图片图标。八方向缩放和标题拖动在 Windows 消息命中阶段处理，避免快速拖动等待绘制命令；内容及窗口按钮保留客户区操作。
- 清理主操作使用底部固定的 48 像素全宽图标加文字按钮；选项独立滚动，确认使用居中弹窗。普通次操作至少 36，并为图标与文字分别留位。三档使用独立 AI 图标，展示真实项目数量和影响，高级选择折叠。
- 开关整行可点击、支持键盘；数值控件支持滑块、直接输入及 30 像素图片加减按钮。导航、窗口和核心操作图标使用 AI 图集切片，不用文字字符代替图标。
- 工作计时使用明确圆环、48 像素全宽主按钮与独立时长/提醒区。运行和暂停禁用方案编辑，当前方案说明保持可读；计时环不持续旋转，只有实际进度更新。

## 素材和开销

原图及完整提示词保存在 `assets/visual/`。Rust 构建阶段按清单切图，输出透明边缘检查、接触表及元数据。控制图标提取连通主体以去掉生成噪点，缩放先预乘 alpha，避免黑边。原失败图保留为记录，不打包。

当前运行目录包含 39 个图标/视觉切片和 1 张背景，原始 RGBA 约 2.58 MiB；这是嵌入素材体积，不等于应用内存占用。图片按需上传纹理并缓存，关闭设置时释放背景纹理；未接入的办公素材不进入当前运行目录。图片不引入运行期解码器或采样线程；诊断仅在主动生成时建立短期采集线程。

外观卡片加入缎面、玻璃及山水材质作为缩略背景，叠加实际数据/宠物，不代表新增桌面主题。图片按透明主体比例绘制。选项和预览独立滚动，小窗口压缩卡片及分隔间距，避免宠物预览退化为小点。完整设置窗回归覆盖底部说明可见及宠物最小尺寸；视觉仍需以真实截图检查。

## 验证边界

诊断页复用玻璃外壳：生成、复制、保存固定在上方，四列资源快照分开标签与数值，进程分组在下方独立滚动。Node/Python 每页 20 项，可切换完整只读原文；打开页面不自动采集。布局测试需同时检查标签与数值分行、四列占用实际宽度及固定操作区，不以按钮出现作为整体布局合格。

每轮启动真实应用，对比同一页面的构图、对齐、对比和操作；测试、构建与保存提交不能替代视觉验收。当前仍是纠偏迭代，不称为最终视觉完成。完整记录见《本轮验证》；分层螺旋和办公扩展见《桌面工作助理规划》，按需计算并默认保持未主动启用的采集关闭。
