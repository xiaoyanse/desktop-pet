# 工作计时

工作计时沿用桌面仪表的玻璃工作台和现有 AI 时钟、播放、暂停图片。设置侧栏和宠物快捷入口可到达；分层螺旋仍待实现，这个入口不是螺旋的替代验收。

## 行为

- 25/5、50/10 分钟预设，以及各 1–1440 分钟的自定义专注/休息。
- 正计时记录已用时长，可以暂停、继续和结束；结束后保留本次时长，重新开始或重置才清除。
- 倒计时向上取整显示剩余秒数。计时依据单调时钟经过的时间，迟到的刷新会直接校正，暂停时间不累计；不依赖资源采样频率。
- 专注结束只提示，不自动开始休息。休息长度在开始本次专注时固定；开始休息需显式点击。方案修改用于下一次专注。
- 运行或暂停期间不能切换模式和时长方案，避免误替换正在进行的任务；可以修改提醒方式。
- 静默不显示桌面提醒；默认标记在悬浮入口显示小钟；卡片用独立置顶工具窗口提示，不播放声音，不主动获取键盘焦点。知道了后不反复提醒；完成状态仍保留在计时页。
- 关闭设置继续计时。退出整个应用结束本次会话，不自动恢复运行中的任务；配置保存时长和提醒偏好，没有保存运行状态或创建后台服务。

## 架构与开销

`domain/work_timer.rs` 定义方案、状态和经过时间规则；`application/work_timer.rs` 维护单调时间锚点和一次提醒；UI 位于 `ui/work_tools/work_timer/`，分成页面、圆环、提醒和输入回归。监视器在正常更新中推进计时，运行时至多额外请求每秒刷新，没有新增线程或系统采集。暂停、结束和空闲不请求计时刷新。

新提醒窗通过已有桌面接口纳入本进程工具窗口，保持托盘行为和非激活创建。只读 inspect 增加 timerReminder 和 active 字段，现场样式与焦点另行验证。

现有图集中的 timer/play/pause 开始用于真实功能，原始 RGBA 新增 48 KiB；PNG 仍只在构建期解码。扩展配置触发通道枚举大小 lint 后，将采样配置命令放入 Box，停止命令保持小尺寸；没有改变采样线程的创建、刷新或关闭约定。

## 验证

完整结果与实机证据见《本轮验证》。状态回归覆盖暂停时长排除、迟到完成、一次提醒、显式休息、运行中禁止覆盖及旧配置默认值；UI 输入覆盖主操作、禁用模式、结束正计时、重置和确认休息。提醒与真实清理、设备录音互不调用。
