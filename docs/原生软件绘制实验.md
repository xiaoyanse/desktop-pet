# 原生软件绘制实验

2026-10-12，基线 `2b0c7f7`。开发实验已接线，普通应用仍使用原后端；不把合成页面的低占用当作整款产品改善。

## 用户最新取舍

100 MB由硬门槛改为优化参考，优先所有已确认功能闭环。保留已接入的字体共享、图集预算及有界业务缓存；本候选不进入普通启动路径，大窗口绘制速度不足时不为低内存牺牲交互。后续按功能交付推进，不继续追逐原硬门禁。

## 实现与入口

`desktop-meter.exe --software-render-probe evidence/尚不存在的文件.jsonl`。

组合根显式装配两个egui上下文、共享系统中文字体、现有AI素材和中立原生输入。纯框架绘制适配器在 `ui/rendering/software`；消息循环/DIB在 `infrastructure/windows/presentation`，不导入egui。实验页面在 `ui/development`，显示合成值并明确开发身份。根窗口240×142，子设置1040×820，最大化按本机工作区2560×1392。原测试布局并不是产品重设计或完整功能入口。

单窗口只持有一个32位top-down DIB，释放旧表面后建立新尺寸，不把整帧复制到第二份Vec。32 MiB表面上限、16 MiB纹理缓存和64张数量上限、最多128个待处理输入；尺寸乘法、网格、纹理更新及采样参数验证后才画。预乘alpha、BGRA、三角形共享边、裁切与双线性过滤有实际像素回归。局部字体更新使用单次流式转换，完整彩色图像借用框架Arc。

缓存上限不是整个进程上限，也不包含框架字体/输出网格、DWM、旧Arc的替换过渡和映射等。纹理批次先验证才更新，不支持重复采样、混合过滤或自定义GPU回调会显式失败；保留这些限制，不称能兼容全部业务。

只在实际输入/窗口变化或egui请求时刷新；不装配采样、报告、清理、录音、托盘或其他工作任务，不写个人配置。日志create_new拒绝覆盖，每秒节流，动作强制记录，总帧记录最多120条，退出追加结果。实验无托盘，普通 `--quit` 不适用；根窗口Alt+F4正常退出，子关闭应仅隐藏，原生生命周期有回归。
