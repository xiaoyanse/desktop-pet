- functional：第一行监测镜片、猫头像、芯片、滑杆；第二行清扫刷、历史时钟、计时器、便签；第三行资源条、办公咖啡、工具箱、截图相机；第四行剪贴板、启动器火箭、报告文档、会议麦克风。

- spiral-islands：第一行资源、办公、工具普通状态；第二行相同三类的选中状态。
- office：第一行录音、最近片段回溯、待办、提醒；第二行截图批注、置顶图片、便签、工作区。

## 构建切图约定（待实现）

由 Rust 构建辅助完成确定性切图与目标尺寸缩放，生成构建目录中的 RGBA 数据。应用按需加载并缓存纹理，避免运行时反复解码或为未打开工具创建纹理。

宽 W、高 H、列数 C、行数 R，单元边界使用整数比例：左 W*c/C，右 W*(c+1)/C；上 H*r/R，下 H*(r+1)/R。功能/控制图宽 1254、办公图宽 1774 不整除列数，禁止仅用 W/C 固定宽度切割而丢弃最右/最下像素。

每个切片需验证非空、alpha/透明留白及对象未跨单元，记录实际边界、输出尺寸、名字与使用处。缩小后核对文字/图标不重叠，普通/悬停/选中/禁用可辨；未通过则不能接入。具体切图工具、产物和运行占用在实际实现后更新，不预先宣称完成。
