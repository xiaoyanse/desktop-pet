# Control icons v4

2026-10-12. Built-in imagegen, transparent background. Purpose: replace the flat white controls with restrained glass pictograms matching the established navy/jade UI. Source atlas is versioned; the old atlas remains available. Generation prompt is retained verbatim below. Runtime acceptance requires semantic, alpha, small-size and native-page review.

Use case: stylized-concept. Asset type: production transparent sprite atlas for a refined Windows desktop assistant with smoky navy frosted-glass UI, jade accent and warm-white typography. Create ONE square atlas, exactly 4 columns by 4 rows, sixteen standalone functional pictograms. These must look like the same family of restrained pearl-silver and smoky blue-gray sculpted glass as the app's glass navigation icons. Shallow bevel, subtle jade edge reflections, gentle top-left highlight, visible midtone blue-gray shading; avoid blown-out pure-white flat silhouettes. No circular carriers: the Rust UI draws its own button surfaces. Frontal view, consistent optical size and medium stroke weight, extremely simple readable shapes that remain clear at 16, 20 and 24 pixels. Strict order left-to-right: row 1 settings gear; upright pushpin; diagonal pushpin crossed by a small clean slash indicating unpin; document list with three horizontal lines and three bullet dots. Row 2 two short stacked rounded horizontal bars for compact view; two overlapping rectangular window outlines for restore/full view; upward chevron; downward chevron. Row 3 close X; confirmation checkmark; plus sign; minus sign. Row 4 minimize short horizontal line positioned below center; maximize square outline; play triangle; pause with two separate equal vertical bars. Preserve recognizable geometries: chevrons must point exactly up/down, close and plus must differ, pause must have exactly two bars. Each icon centered in the middle 55 percent of an equal cell, consistent optical weight, ample empty transparent space. Preserve holes in outlines. True transparent alpha background, no checkerboard, no grid lines, no tile backgrounds, no text, letters, labels, numerals or watermark. Absolutely no detached speckles, fog, halos, cloud texture, cast shadows or ornaments outside icon silhouettes. Clean local antialiasing only along edges. This will be cut into actual embedded UI textures; it is not a design board or mockup.
