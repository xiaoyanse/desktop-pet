# 内置宠物素材

`atlas.png` 使用 Codex 内置图像生成工具，按用户要求生成并编辑为透明背景。三列依次为小猫、狐狸和猫头鹰，两行分别为睁眼和闭眼。PNG 中透明像素仍有 RGB 信息，不能仅根据查看器显示的背景判断透明度。

构建时生成六张 96×96 RGBA 数据，运行时按需载入纹理；没有运行时图像生成、解码器或在线模型。头部通过局部网格变形、眼睛通过局部 UV 位移跟随鼠标，不是三维骨骼模型。鼠标跟随、悬停、点击与拖放动画均由 Rust 绘制，外观设置可关闭。

生成方向：柔和三维风格，小猫戴石墨色耳机、狐狸戴青绿围巾、猫头鹰戴眼镜；保持三列两行布局、中心对齐、开放与闭合眼睛对应；透明背景，无文字和界面元素。
