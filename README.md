# 桌面资源监视器

纯 Rust 的 Windows 桌面悬浮监视器。监测 CPU、内存、内核池、多块 GPU、磁盘和网络，按需查看进程排行。界面使用 egui/eframe，不依赖浏览器、Node.js 或 Python。

## 项目结构

```text
src/
  main.rs                       # 启动入口、依赖装配
  ui/
    monitor.rs                  # 主界面协调与稳定入口
    common/                     # 主题、图像缓存、图标、控件、共享清理确认
    monitoring/                 # 资源卡片、详情、趋势、悬停操作
    companion/                  # 宠物、动作与快捷入口
    work_tools/work_timer/      # 工作计时页面、圆环与提醒
    work_tools/diagnostic_report/ # 诊断入口、固定操作与只读预览
    work_tools/screenshot/      # 截图入口、批注画布、预览和独立贴图
    monitor/work_timer.rs       # 主循环计时接线
    settings/
      pages/                    # 按功能划分的设置页面
      shell/                    # 导航、自绘标题栏与缩放
  application/                  # 用例、后台任务、服务协调
  domain/                       # 数据模型、设置规则、清理策略
  interfaces/                   # 监测、桌面、存储、清理的接口契约
  integration_tests/            # 仅测试编译：真实装配的跨层回归
  infrastructure/
    windows/
      desktop/                  # 窗口、托盘、菜单、拖动与贴边
      monitoring/               # Win32、PDH、DXGI 与进程采样
      fonts.rs                  # 只读系统字体映射及进程内共享
      memory/                   # 清理操作与管理员辅助进程
      report/                   # 只读进程快照、路径与创建时间校验
      screenshot/               # 原生选区、窗口识别、GDI 捕获与图片剪贴板
    storage/                    # JSON 设置、操作记录、UTF-8 诊断报告
tests/                          # 跨模块与架构回归测试
docs/                           # 需求、架构、变更与验证记录
scripts/                        # 开发与验证辅助脚本
```

具体依赖边界和新功能接入方式见 [架构说明](docs/architecture.md)。

## 开发与验证

需要 Windows 和 Rust MSVC 工具链。

```powershell
cargo test -j 1
cargo clippy --all-targets -j 1 -- -D warnings
cargo build --release -j 1
```

运行 `target/release/desktop-meter.exe`。设置存于 `%LOCALAPPDATA%/DesktopMeter/settings.json`；升级目录结构不会改变用户设置位置。

`desktop-meter.exe --settings` 直接打开设置，已有实例时转到该实例的设置窗口；可用于设置专用快捷方式。`--quit` 正常退出已有监视器实例，保留设置。

诊断命令 `--probe <输出文件>` 采集资源样本，`--inspect <输出文件>` 读取当前悬浮窗边界。这两项只读，不执行内存清理。

`--report-probe <输出文件>` 手动采集同一报告链路并写指定开发验证文件；日常使用设置页“诊断报告”的生成、复制和保存，保存不会覆盖已有报告。

## 使用

截图入口在设置“截图与贴图”以及宠物“工具”分支。可选全屏、矩形区域、自由形状、识别窗口；选区 Enter 确认，Esc/右键取消，矩形方向键微调、Shift＋方向键改大小。窗口截图捕获可见范围，不恢复被其他窗口遮挡的内容。批注后可复制图片、保存 PNG 或置顶贴图；贴图可以拖动、缩放和关闭，当前限单张，新的贴图替换上一张。默认保存到可执行文件所在盘的 DesktopMeterData/Screenshots，可改绝对路径，设置自动保存。当前测试与尚未现场验收范围见 [截图功能与同行参考](docs/截图功能与同行参考.md)。

- 鼠标移入悬浮窗显示覆盖式图标栏：设置、固定位置、进程详情、完整/精简切换、快速清理、宠物。鼠标移开后隐藏，不占固定空白区域。
- 精简视图保留资源名称和数值。还原图标、托盘单击、Ctrl+Alt+M 均可恢复完整视图；双击精简卡片也可还原。
- 卡片内容区域用 Windows 原生机制拖动；靠近显示器工作区四边自动吸附。关闭吸附仍保留窗口边界限制。托盘可启用鼠标穿透。
- 设置窗口使用自绘标题及窗口操作，支持拖动、边缘缩放、最小化和最大化；关闭设置不退出监测器。监测项支持分类筛选、启用、排序、趋势与颜色阈值。
- 外观页左侧调整、右侧即时预览，可独立关闭背景和边框，选择主题色与透明度。开关支持键盘；数值支持输入、滑块和加减按钮。
- 清理中心提供轻度、中度、重度三个有说明的推荐档位，八种操作仍可高级自定义。轻度默认只清低优先级待机缓存，优先减少对正在进行工作的影响。清理主按钮全宽显示，先确认本次清单，再执行并请求必要的管理员授权。详情见 [清理档位与交互](docs/清理档位与交互.md)。
- 自动规则默认关闭，要求程序已有管理员权限；默认排除影响应用或磁盘的项目。界面显示实际可执行的自动项目，敏感操作须明确允许。
- 悬停清扫图标或宠物会打开窗口外的快捷面板，轻度清理使用相同的主按钮和确认流程；中重度入口打开完整清理中心。快捷入口不会修改原有的清理选项或自动规则。
- 宠物模式内置 AI 绘制的小猫、狐狸、猫头鹰，保留 RAM/CPU 数值；头部和眼睛跟随全屏鼠标，悬停抬头与呼吸、点击回应、拖放摇摆回弹、周期眨眼。动画最高约 15 帧/秒，鼠标稳定时降频；关闭动画后停止全局鼠标轮询。双击、快捷面板还原图标或托盘单击均可恢复完整视图。
- 工作计时提供 25/5、50/10、自定义专注/休息和正计时，支持暂停、继续及结束保留时长。默认到时只显示标记，也可静默或用不抢焦点卡片提醒；专注结束手动开始休息。关闭设置继续计时，退出整个应用结束本次会话。详见 [工作计时](docs/工作计时.md)。分层螺旋接入资源、办公、工具分类和真实子功能，试用与日常桌面的现场验收分列。
- 诊断报告手动采集资源、内核池、CPU/内存前五名及 Node/Python 来源，预览后复制或保存至本地。个人与项目目录脱敏，不读取启动参数，不能单凭运行时路径认定具体 MCP；只保留一份快照，打开页面不自动采集。详见 [诊断报告](docs/诊断报告.md)。
- 托盘菜单为每种操作绘制不同图标。正常监测与快捷面板不进入任务栏或 Alt+Tab；打开设置后，设置窗口显示在任务栏。
- 数值和单条进度条使用分级颜色；连续超限另以小红点标记，避免误认为两条进度条。

中文由应用加载系统微软雅黑/黑体字体处理；不会使用图标字体中缺失的符号充当按钮。AI 生成的图像由 Rust 构建工具切图，按需加载到设置、悬浮操作栏和原生菜单；控制图标不使用文字符号。设置使用烟蓝玻璃材质、品牌侧栏与圆形窗口按钮；材质为静态图像，没有实时读取桌面作模糊。没有运行时 Node.js、Python、WebView、PNG 解码或图像生成依赖。

范围与验证见 [Mem Reduct 接入说明](docs/memreduct研究与接入.md) 和 [本轮验证](docs/本轮验证.md)。扩展选择与未实现范围见 [采访规划](docs/桌面工作助理规划.md)。

系统中文字体优先只读映射，进程内共享，避免框架复制完整字体；映射失败回退为一份共享字节。不会裁掉中文字符或修改系统字体。原理、内存口径和验证限制见 [字体加载与常驻占用](docs/字体加载与常驻占用.md)。

当前优先所有已确认功能闭环。用户已将100 MB硬上限改为尽量优化；资源测量继续随阶段记录，不为追求该数值暂停功能开发。显式开发入口 `--software-render-probe <尚不存在的日志路径>` 验证原生软件绘制，未替换普通后端且不支持普通托盘命令；实验不属于用户功能，限制见 [原生软件绘制实验](docs/原生软件绘制实验.md)。
